    How this is scored

    Every player gets one score built from three things: underlying quality, how easy their next fixture is, and a small bump for playing at home. No black box — the number next to each name on the right is that total, high to low.

    "Underlying quality" blends recent form with season-long points-per-game, so one huge or awful match doesn't swing a player's number too far, plus real chance quality — expected goal involvements (xG + xA) for attackers, expected goals conceded for defenders — so a player's actual goal threat or clean-sheet odds count for more than a small run of results.

    Players who are injured, suspended, or barely playing are left off the list entirely.
